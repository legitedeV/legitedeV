I design and build company websites, landing pages, online stores and web applications. I work with Next.js, React, TypeScript, Tailwind, Node.js and PostgreSQL; animations in GSAP and Three.js. Plus admin panels, API integrations, technical SEO and performance. Design and code come from one pair of hands, so the site stays consistent from mockup to launch.

Collaboration is remote and in writing: quote, design and deployment by one person, no sales rep and no middlemen. After delivery you get 30 days of revisions. Most client work lives in private repositories, so the portfolio below consists of concepts for my own brands: they show style and technique.

## Open source tools

- **[Usage4Claude-LINUX](https://github.com/legitedeV/Usage4Claude-LINUX)**: Claude usage limits in the terminal, waybar and tray (Linux port).
- **MaxSwitch**: automatic switching between Claude Max subscriptions when limits hit, systemd watchdog and MCP server (private repo).
- **mcp-humanizer**: MCP server for humanizing Polish text without its own API (private repo).
